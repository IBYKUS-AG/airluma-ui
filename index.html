Light / dark review

Every component of the design system, with every state the dark mode repaints. The colour scheme follows the operating system until the button on the right forces one - the choice is kept in localStorage and applied before the first paint on the next visit.

The dark colours cover 289 selectors that describe a state an element simply has, and every one of them has an example below. The remaining 105 describe a state the pointer or the keyboard has to create, and no markup can show them: force those per element in the DevTools element state panel (:hov, :act, :foc). Four more need one interaction each - open a dialog with its button, hover the dropdown row that carries a submenu, hover a table cell for the column highlight, and select some text for ::selection.
